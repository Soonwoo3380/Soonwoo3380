## 📌 주요 프로젝트

### 1. 그래프 신경망 기반 토픽 모델

확률 정보와 임베딩 정보를 하나의 그래프 구조에서 통합하는
그래프 기반 토픽 모델을 연구한 석사학위 논문입니다.

- LDA 기반 단어 간 확률 관계와 SBERT 임베딩 정보 통합
- 임베딩을 노드 특성으로, 확률 관계를 엣지로 구성
- GCN과 DMoN 클러스터링을 결합한 end-to-end 프레임워크 구축
- 여러 그래프 구조와 연결 방식 직접 비교
- 토픽 응집도 기준 LDA 대비 약 28%, BERTopic 대비 약 18% 개선
- 석사학위 논문 및 학술논문으로 발전

Repository: [gnn-topic-model](https://github.com/Soonwoo3380/gnn-topic-model)

---

### 2. 응용 머신러닝 경진대회

데이터가 생성되는 맥락을 이해하고,
문제를 설명하는 특성을 설계한 뒤 모델링 결과를 검증하는 방식으로 진행한 프로젝트입니다.

#### 온라인 채널 제품 판매량 예측
- LG Aimers 3기
- 최종 **747팀 중 57위**
- 모델 튜닝만으로 성능이 정체되자 입력 정보 자체를 다시 검토
- 제품 간 관계, 소비 주기, 요일, 공휴일 등의 특성 추가

#### 제품 이상 여부 판별
- LG Aimers 5기
- 최종 **740팀 중 31위**
- 변수가 생성된 제조 공정을 기준으로 데이터 구조 분석
- 공정별 분리 모델링, 클래스 불균형 대응, 앙상블 적용

#### 뉴스 기사 레이블 복구
- SentenceBERT와 KMeans를 활용한 비지도 텍스트 분류
- 클러스터별 주요 키워드와 대표 문장을 분석해 레이블 복구
- 최종 **129팀 중 8위**

Repository: [competition](https://github.com/Soonwoo3380/competition)

구조와 동작 방식을 이해하기 위해 직접 구현하고 실험한 프로젝트입니다.
